Rules

  1. Only tokens in code. No hex codes anywhere else.
  2. Urgency is always a filled red-600 tag with a word — ESCALATED, SLA BREACH. Never colour alone.
  3. Gold is only grade and rewards. Never on red. Never a large filled area.
  4. Meaning colours are never decorative.
  5. Every colour carries an icon and a word with it.
  6. Blue blocks go below the job list, never above.
  7. Light and dark mode only. No colour picker. Light designed first.
  8. Design in Hindi first, check in English. Never truncate — wrap to a second line.
  9. Nothing below 12px. Body never below 16px.
  10. No colour that is not on this page.
